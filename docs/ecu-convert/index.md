# RC51 ECU Conversion – Project Overview

This section of the documentation covers the complete process of converting a Honda RC51 to run on a modern aftermarket ECU. The goal is to provide a clear, technically accurate reference for anyone attempting a similar build — whether on an RC51 or another platform.

This project is actively evolving as testing, validation, and refinement continue. Pages in this section will be updated as new information becomes available.

---

## 🔧 Current Project Status

**ECU Selected:** FuelTech FT550  
**Harness:** Completed, in testing phase  
**Sensors:** OEM + upgraded pressure and wideband systems  
**Documentation:** Ongoing documentation

### What’s Completed
