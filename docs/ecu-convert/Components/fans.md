# SPAL Fans

This guide details the SPAL fan upgrade for my Honda RC51 custom ECU build, including specifications, connector details, and installation notes.

## SPAL Fans Overview

Like many RC51 owners, I upgraded the OEM fans to SPAL pusher fans (Part Number: **30103013**) for better cooling performance. I’ll update the mods section of this website later with details on the brackets used for installation.

## Connector Specifications

The SPAL fans come with their own connectors, but I replaced them with **DT04‑2P** connectors to match my custom harness. I’ll update this document later with the OEM SPAL connector specifications.

### SPAL Fan Connector Data

| Connector Type | Part Number | Description |
|----------------|-------------|-------------|
| Custom | [DT04‑2P](https://www.te.com/en/product-DT04-2P.html) | 2‑pin connector used in custom harness for SPAL fans. |

> Refer to the [Main Harness](/) documentation for wiring details and the [Mods](/) section (forthcoming) for bracket installation instructions.
