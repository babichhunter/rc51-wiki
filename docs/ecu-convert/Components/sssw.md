# Sidestand Switch

This guide provides detailed information about the sidestand switch (SSSW) used in the Honda RC51 ECU build, including its functionality, wiring, and connector details.

## Sidestand Switch Description

The Honda RC51 features a standard sidestand switch that has continuity when the stand is up and no continuity when it is down. For my build, this switch is connected via the [Main Harness](/) and, like the OEM logic, provides a path for the starter relay to ground.

Unlike the OEM logic, lowering the sidestand with the engine running does **not** shut off the engine.

> **IMPORTANT NOTE:**  
> Refer to the [Main Harness](/) documentation for detailed wiring instructions for the sidestand switch.

## Sourcing the Sidestand Switch Connector

For my build, I replaced the OEM connector with a **DTM04‑2P**. I will update the OEM connector specification later.
