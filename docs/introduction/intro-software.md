This page outlines the software tools I used throughout the ECU integration and documentation process. These tools helped with everything from 3D scanning and modeling to wire diagram creation and symbol design.

## 📱 3D Scanning

- **[Polycam (iPhone)](https://poly.cam/)** – Used for capturing 3D scans of components and layout areas. Great for quick geometry reference and spatial planning.

## 🧩 CAD Modeling & Symbol Design

- **[SolidWorks](https://www.solidworks.com/)** – Used for solid modeling of custom trays, mounts, and enclosures. Also used to design wire diagram symbols and layout templates.  
- **[Fusion 360](https://www.autodesk.com/products/fusion-360/personal)** – Could be used as an alternative to SolidWorks. It’s more accessible and cloud‑based, but I personally used SolidWorks for this build.

## 📊 Wire Diagram Creation

- **[Draw.io](https://www.drawio.com/)** – Used for creating clean, scalable wire diagrams. It’s free, browser‑based, and supports custom symbols and layering.

> **Note:** While some of these tools are paid (like SolidWorks), there are free or lower‑cost alternatives available for most tasks. I used what I had access to, but you can replicate most of this workflow with free software if needed.
