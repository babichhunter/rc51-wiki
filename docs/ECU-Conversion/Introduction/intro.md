# Aftermarket ECU Conversion – Honda RC51

This wiki documents the process of converting a Honda RC51 to run on an aftermarket ECU, most specifically a FuelTech FT550 ECU. The goal is to provide a clear, technically sound guide for enthusiasts and builders who want more control, flexibility, and diagnostic capability than the OEM ECU allows.

A guide like this would have been incredibly useful when I started this project. I spent countless hours searching for a comprehensive walkthrough on applying an aftermarket ECU to a motorcycle. While information exists, it’s often scattered — good documentation on one topic, missing pieces on another, and very little that ties everything together for a specific application.

Hopefully this guide will not only serve as a resource for the Honda RC51, but also help others working on different motorcycles or cars. 

## Getting Started

I recommend reading the rest of the introduction material to get a better overview of the scope of this project and how to navigate the documentation. This wiki is designed to guide you step‑by‑step through most sections of the build.

That said, it’s almost guaranteed that I’ve missed something, documented something incorrectly, struggled to translate what’s in my head into words, or am simply wrong in some areas. This is my first time attempting this build, and mistakes are inevitable despite my best efforts.

If you see incorrect or unclear information, please admin@hondarc51.com with questions or suggestions. Even if something just needs more explanation, I want this documentation to be as accurate and helpful as possible.
